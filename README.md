# Projeto 2 — Sprint 1

Códigos de apoio em Python/Google Colab para a análise estatística antes e depois de uma intervenção.

## Conteúdo
- `AGENTS.md`: regras e orientações para desenvolver e revisar os códigos.
- `requirements.txt`: bibliotecas necessárias.
- `notebooks/`: pasta destinada ao notebook `.ipynb` exportado do Google Colab.

## Como executar
1. Abra o Google Colab: https://colab.research.google.com/
2. Crie um notebook e copie as células de código preparadas para as Questões 2 a 8.
3. Faça upload das duas planilhas Excel quando solicitado.
4. Ajuste o nome exato da coluna, a unidade de medida e os limites de referência.
5. Execute as células em ordem e interprete os resultados no contexto do problema do grupo.

## Cuidados
Não envie ao GitHub dados pessoais, planilhas privadas ou informações confidenciais. Os valores de exemplo do código precisam ser substituídos pelos valores adequados ao problema real. Os resultados descritivos não comprovam, por si só, a eficácia causal da intervenção.
